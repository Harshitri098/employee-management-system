# Employee Management System

## About the Project
This is a beginner-level C++ mini project created to practice Object-Oriented Programming (OOP) concepts.

The program represents employees with different roles, including Developer and Manager, and displays their details.

## Concepts Used
- Hierarchical Inheritance
- Classes and Objects
- Constructors
- Protected Members
- Function Overriding
- C++ Output (`cout`)

## Classes
- **Employee:** Base class containing employee name and salary.
- **Developer:** Derived class that adds a programming language.
- **Manager:** Derived class that adds team size.

## How to Run
1. Compile the program using a C++ compiler.
2. Run the generated executable.

Example using g++:

```bash
g++ EmployManag.cpp -o EmployeeManagement
```

Run on Windows:

```bash
EmployeeManagement.exe
```
